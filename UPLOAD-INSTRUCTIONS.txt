PLACON PREMIUM WEBSITE PREVIEW

1. Open the `placon` GitHub repository.
2. Upload ALL files from this ZIP directly to the repository root.
3. Choose to replace existing files when GitHub asks.
4. Do NOT add a CNAME file yet.
5. Settings → Pages:
   Branch: main
   Folder: /(root)
6. Wait 1–2 minutes.
7. Open your existing GitHub Pages preview URL.
8. Hard refresh:
   Windows: Ctrl + Shift + R
   Mac: Command + Shift + R

This package intentionally keeps the custom domain disconnected until you approve the website.
